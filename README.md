# SUKA Frontend

Landing page SUKA AI — AI Business Partner untuk membantu pengguna memahami tantangan dan mengambil langkah bisnis dengan lebih jelas.

## Stack
- React 18
- Vite 6
- CSS responsive tanpa UI framework tambahan

## Menjalankan lokal
```bash
npm install
npm run dev
```

Build produksi:
```bash
npm run build
npm run preview
```

## Interaksi
- Maskot SVG 3D-inspired dengan mata mengikuti pointer secara real-time.
- Animasi mengambang ringan dan menghormati `prefers-reduced-motion`.
- Form pertanyaan masih berupa UI; belum terhubung ke layanan chat/backend.

## Catatan
Tautan navigasi dan CTA saat ini adalah anchor placeholder sampai rute produk dan autentikasi tersedia.
